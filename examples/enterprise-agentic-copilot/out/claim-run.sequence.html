Flow

  1. 1The customer asks in Teams or web chat; Copilot Studio signs them in with Entra ID.
  2. 2Copilot Studio calls the AI gateway with the user's token and the case id.
  3. 3API Management → Claims orchestrator (validated request)
  4. 4Claims orchestrator → Content Safety (screen prompt)
  5. 5The policy agent retrieves coverage clauses from the indexed wording.
  6. 6The fraud-signal agent asks the Fabric data agent, which runs governed queries as the signed-in user.
  7. 7The action agent calls the claim tool API with the proposed payout.
  8. 8The tool API starts the approval flow, which asks an adjuster in Teams.
  9. 9Approval flow → Approval flow (adjuster approves in Teams)
  10. 10Approval flow → Dataverse (record decision)
  11. 11Below the threshold the orchestrator's action agent records the payout directly, with the same audit trail.
