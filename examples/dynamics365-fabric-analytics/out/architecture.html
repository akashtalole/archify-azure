Dynamics 365 Business Central and customer engagement apps: operational data to Microsoft Fabric analytics

Flow

  1. 1An extract function reads changed Business Central records through the API v2.0 (filtered by last modified time) using a service principal
  2. 2The function writes initial and incremental change files to the open mirroring landing zone; Fabric applies them to Delta tables
  3. 3Dynamics 365 Sales → Dataverse (tables)
  4. 4Link to Microsoft Fabric creates a lakehouse with read-only shortcuts to Dataverse tables; data stays in Dataverse and refreshes within about an hour
  5. 5Open mirrored database → Curated lakehouse (shortcut / SQL)
  6. 5Dataverse lakehouse → Curated lakehouse (shortcut)
  7. 6Curated lakehouse → Semantic model (Direct Lake)
  8. 7Semantic model → Power BI (report)
  9. 8Semantic model → Fabric data agent (ground)
  10. 9Sales and service teams → Dynamics 365 Sales (work)
  11. 9Finance and operations → Business Central (post)
