Flow

  1. 1Business Central → Extract function (API v2.0)
  2. 2Sales and Customer Service → Dataverse (tables)
  3. 3Finance and Operations → Dataverse tables (entities)
  4. 4Extract function → Open mirrored database (landing zone)
  5. 5Dataverse → Dataverse lakehouse (Link to Fabric)
  6. 5Dataverse tables → Dataverse lakehouse (Link to Fabric)
  7. 6Open mirrored database → Silver lakehouse (mirror)
  8. 6Dataverse lakehouse → Silver lakehouse (shortcut)
  9. 6Pipeline or copy job → Silver lakehouse (load)
  10. 7Silver lakehouse → Gold warehouse (model)
  11. 8Gold warehouse → Semantic model (Direct Lake)
  12. 9Semantic model → Power BI (report)
  13. 9Semantic model → Fabric data agent (ground)
