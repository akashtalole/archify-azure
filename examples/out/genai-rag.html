Recommendation. Put Azure Web Application Firewall (on Front Door or Application Gateway) and DDoS Protection in front of every internet-facing entry point; start in detection mode, then enforce.

Priority. Delegate · effort Low · owner Security engineering

To confirm not drawn, so not counted as gaps

  • No private endpoints shown for PaaS data services SE:06, SE:04 — Disable public network access on PaaS data services (Storage, SQL, Cosmos DB, Key Vault) and connect through Azure Private Link private endpoints with private DNS zones.
  • No threat detection or posture management shown SE:10, SE:01 — Enable Microsoft Defender for Cloud and Microsoft Sentinel, assign Azure Policy initiatives for the baseline, and send activity and diagnostic logs to a central, access-restricted Log Analytics workspace.
  • No backup or recovery capability shown RE:09 — Protect data with Azure Backup (vault with soft delete and cross-region restore where required) or database point-in-time restore, and test restores against your RPO/RTO.
  • No infrastructure-as-code or CI/CD shown OE:05, OE:11 — Define infrastructure as code (Bicep or Terraform) and deploy through a pipeline with small, reversible changes, environment promotion and automated rollback.
  • No CDN / global edge shown for end users PE:03, PE:09 — Serve content and terminate TLS close to users with Azure Front Door or Azure CDN to reduce latency.
  • No cost visibility shown CO:03, CO:04, CO:01 — Set Microsoft Cost Management budgets with alert thresholds and enforce cost-allocation tags (Azure Policy) so spend maps to this workload.
  • Single-region model inference RE:05, RE:06 — Plan for throttling and quota limits (retries, queuing, provisioned throughput units) and consider global or data-zone deployments, a second region or a fallback model.
  • Model cost controls CO:07, CO:12 — Select the smallest model that meets quality targets; use prompt caching and batch deployments where possible; track cost per request.

Cross-pillar trade-offs

  • Content safety on model traffic Security ↔ Cost Optimization ↔ Performance Efficiency
    Content Safety costs $150.00/month (16% of AI spend) and adds a synchronous screening step to each model call. Resolution: Apply the strictest checks where harm is highest (final responses, PII) and measure per-check value before enabling every check on every call.
  • Observability volume Operational Excellence ↔ Cost Optimization
    Log Analytics is $126.50/month in this estimate, mostly log ingestion; richer telemetry improves detection but ingestion is billed per GB. Resolution: Sample verbose traces, set retention per table (Basic logs for high-volume, low-value data) and keep full-fidelity logs for security and audit sources only.
