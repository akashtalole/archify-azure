To confirm not drawn, so not counted as gaps

  • No private endpoints shown for PaaS data services SE:06, SE:04 — Disable public network access on PaaS data services (Storage, SQL, Cosmos DB, Key Vault) and connect through Azure Private Link private endpoints with private DNS zones.
  • No threat detection or posture management shown SE:10, SE:01 — Enable Microsoft Defender for Cloud and Microsoft Sentinel, assign Azure Policy initiatives for the baseline, and send activity and diagnostic logs to a central, access-restricted Log Analytics workspace.
  • No backup or recovery capability shown RE:09 — Protect data with Azure Backup (vault with soft delete and cross-region restore where required) or database point-in-time restore, and test restores against your RPO/RTO.
  • No infrastructure-as-code or CI/CD shown OE:05, OE:11 — Define infrastructure as code (Bicep or Terraform) and deploy through a pipeline with small, reversible changes, environment promotion and automated rollback.
  • No CDN / global edge shown for end users PE:03, PE:09 — Serve content and terminate TLS close to users with Azure Front Door or Azure CDN to reduce latency.
  • No cost visibility shown CO:03, CO:04, CO:01 — Set Microsoft Cost Management budgets with alert thresholds and enforce cost-allocation tags (Azure Policy) so spend maps to this workload.
