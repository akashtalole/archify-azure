Multi-agent assistant: Copilot Studio, Azure AI Foundry and Microsoft Fabric

Flow

  1. 1An employee asks a question in Teams or Microsoft 365 Copilot; Copilot Studio authenticates them with Entra ID
  2. 2Copilot Studio hands complex requests to the Foundry orchestrator through the API Management AI gateway, passing the user's token
  3. 3API Management → Orchestrator agent (invoke)
  4. 4The orchestrator asks the model to plan and pick specialist agents; prompts and replies pass Content Safety
  5. 5Orchestrator agent → Data agent (connected agent)
  6. 5Orchestrator agent → Knowledge agent (connected agent)
  7. 5Orchestrator agent → Action agent (connected agent)
  8. 6The knowledge agent retrieves grounding passages from Azure AI Search
  9. 6The data agent queries governed lakehouse and semantic-model data through a Fabric data agent, as the signed-in user
  10. 6The action agent calls approved workflows (ticketing, approvals) in Logic Apps; high-impact actions need human approval

Cross-pillar trade-offs

  • Content safety on model traffic Security ↔ Cost Optimization ↔ Performance Efficiency
    Content Safety costs $150.00/month (5% of AI spend) and adds a synchronous screening step to each model call. Resolution: Apply the strictest checks where harm is highest (final responses, PII) and measure per-check value before enabling every check on every call.
  • Observability volume Operational Excellence ↔ Cost Optimization
    Log Analytics is $11.50/month in this estimate, mostly log ingestion; richer telemetry improves detection but ingestion is billed per GB. Resolution: Sample verbose traces, set retention per table (Basic logs for high-volume, low-value data) and keep full-fidelity logs for security and audit sources only.
